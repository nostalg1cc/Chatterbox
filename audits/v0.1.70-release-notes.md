Nitro v0.1.70 fixes voice and screen-share recovery and strengthens backend authorization.

- Canceled joins and stale heartbeat/recovery results cannot replace a newer call. Leaving stops pending microphone and screen connections immediately.
- Healthy audio survives signaling-only interruptions. Expired room leases recover after sleep or longer outages; takeovers revoke the old signaling capability.
- Screen publishing and viewing have separate ownership, cancellation and recovery. Existing shares are announced to late joiners, and long shares renew before provider authorization expires.
- Relay credentials renew proactively. Microphone removal, suppression changes and optional echo cancellation apply during calls; connection diagnostics can be saved locally.
- Reconnected chat/friend subscriptions refresh their server snapshots.
- Friendship parties are immutable. Preview destinations reject private/reserved addresses and pin DNS; provider-backed previews send only canonical public IDs.
- Chat attachments use authorized, expiring downloads. Deleted attachments stop receiving new links; Cloudinary assets are authenticated and public CDN copies were invalidated. Previously saved copies cannot be recalled.
- Backend quotas and a private scheduled-cleanup key limit misuse. Deployment inputs exclude signing/recovery files and local experiments.

Both participants should update: the tightened voice authorization requires v0.1.70.

Validated with production builds, deterministic lifecycle/security regressions, database permission/rotation tests, live signed image/video downloads (valid accepted, expired/forged rejected), production startup checks, and updater signature verification.
